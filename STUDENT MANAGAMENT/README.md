# CampusConnect
## Student Activity Management Portal

### Project Description
CampusConnect is a university student activity
management portal developed using HTML5, CSS
and JavaScript.

### Objectives
- Display upcoming university events.
- Explore university activities.
- Provide student registration.
- Improve accessibility and usability.

### Technologies Used
1. HTML5
2. CSS3
3. JavaScript
4. Visual Studio Code
5. Git and GitHub

### Main Features
- Semantic HTML structure
- Responsive website design
- Accessible registration form
- Form validation
- Interactive confirmation message
- Keyboard navigation support

### Project Files
- index.html
- style.css
- script.js
- accessibility-audit.md

### How to Run
1. Open the project in VS Code.
2. Open index.html.
3. Right-click and select Open with Live Server.
4. View the website in your browser.

### Conclusion
The project demonstrates semantic HTML,
web accessibility, browser interaction and
Git version control.
